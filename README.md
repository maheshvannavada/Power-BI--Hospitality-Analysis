AtliQ Hospitality Analysis – Power BI Project

📌 Project Overview

The AtliQ Hospitality Analysis project is a comprehensive business intelligence solution built using Power BI to analyze hotel performance across multiple cities, properties, room categories, and booking platforms. This dashboard enables stakeholders to monitor revenue, occupancy, bookings, and realization trends while identifying areas of revenue leakage such as cancellations and no-shows.

The project is designed to replace static Excel-based reporting with interactive, data-driven dashboards that support faster and smarter decision-making for hospitality leaders.

🛠️ Tool Stack

● Power BI Desktop – Data modeling, visualization & dashboarding

● DAX – Calculated measures and KPIs

● SQL – Data extraction and transformation

● Excel – Initial data validation and exploration

📊 Key Metrics Tracked

● Total Revenue

● Total Bookings

● Occupancy %

● ADR (Average Daily Rate)

● RevPAR (Revenue per Available Room)

● DSRN (Daily Sellable Room Nights)

● DBRN (Daily Booked Room Nights)

● DURN (Daily Utilized Room Nights)

● Cancellation %

📈 Dashboard Pages & Insights
🏠 Home Page
● Central navigation hub for the entire AtliQ Hospitality Analysis report
● High-level introduction to booking, revenue, performance, and rating dashboards
● Clean, premium hospitality-themed design for executive viewing with KPI cards and filters

📘 Booking Overview
● Analysis of bookings by platform (makeyourtrip, logtrip, etc.), city, room type, and property
● Key indicators for checkout rate, 24.83% cancellation %, and no-show %
● Helps identify booking behavior patterns and platform dependency

💰 Revenue Overview
● Revenue distribution by city (Mumbai, Bangalore, etc.), category (Luxury vs Business), and property
● Comparison between generated vs realized revenue across properties
● Booking platform-wise revenue contribution analysis

📉 Performance Overview
● Trend analysis of RevPAR, ADR, and Occupancy % (40.59% avg) over time
● Week-wise performance monitoring with occupancy trends (Week 18-19 peak)
● Property-level performance comparison to identify underperforming hotels

🎯 Business Value
● Enables finance teams to track revenue realization (299M loss) and profitability
● Helps sales & marketing teams identify high-performing cities and platforms
● Assists operations teams in monitoring occupancy and capacity utilization
● Provides executives with interactive snapshot of overall business health
