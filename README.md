# AtliQ-Hospitality-Analysis

## 📌 Project Overview
The AtliQ Hospitality Analysis project is a comprehensive business intelligence solution built using Power BI to analyze hotel performance across multiple cities, properties, room categories, and booking platforms. This dashboard enables stakeholders to monitor revenue, occupancy, bookings, and realization trends while identifying areas of revenue leakage such as cancellations and no-shows.

The project replaces static Excel-based reporting with interactive, data-driven dashboards that support faster and smarter decision-making for hospitality leaders.

## 🛠️ Tool Stack
**Skills, Tools & Techniques Used**  
▶️ **Power BI Desktop** – Data modeling, visualization & dashboarding  
▶️ **DAX** – Calculated measures for Revenue, Occupancy %, ADR & RevPAR  
▶️ **SQL** – Data extraction, transformation & ad-hoc analysis  
▶️ **Power Query (ETL)** – Data cleaning and shaping hospitality datasets  
▶️ **Data Modelling** – Star-schema relationships for multi-table analysis  
▶️ **Time-Based Analysis** – Trends, week/month performance tracking  
▶️ **Interactive Reporting** – Slicers, filters, drill-downs, cross-highlighting  
▶️ **Data Visualization** – KPI cards, maps, trend charts, comparative tables  
▶️ **Business Analysis** – Hospitality KPIs & revenue leakage insights  

## 📊 Key Metrics Tracked
- **Revenue**: Total, Generated vs Realized, Revenue Loss (299M)  
- **Bookings**: Total 135K, Cancelled 33K (24.83%), Successful 94K  
- **Occupancy**: 40.59% average, property-wise performance  
- **Performance**: RevPAR, ADR, DSRN, DBRN, DURN trends  
- **Rating**: 3.62 average across properties and room classes
